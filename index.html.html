          إعداد الخادم (مرة واحدة)

          الحسابات والأصدقاء يحتاجان قاعدة بيانات. المشروع يعمل على Firebase المجاني من جوجل، وكل المطلوب منك لصق بيانات مشروعك في أعلى الكود.

          الخطوات كاملة
          1. ادخل console.firebase.google.com وأنشئ مشروعًا جديدًا.
          2. Build ← Authentication ← Sign-in method ← فعّل Google.
          3. Build ← Realtime Database ← Create database.
          4. Project settings ← Your apps ← Web ← انسخ كائن firebaseConfig.
          5. الصقه في المتغير FIREBASE_CONFIG أعلى سكربت الصفحة.
          6. Authentication ← Settings ← Authorized domains ← أضف نطاق موقعك.
          7. الصق قواعد الأمان التالية في Realtime Database ← Rules.
          {
  "rules": {
    "users": {
      ".read": "auth != null",
      "$uid": { ".write": "auth != null && auth.uid === $uid" }
    },
    "codes": {
      ".read": "auth != null",
      "$c": { ".write": "auth != null && (!data.exists() || data.val() === auth.uid)" }
    },
    "emails": {
      ".read": "auth != null",
      "$e": { ".write": "auth != null && (!data.exists() || data.val() === auth.uid)" }
    },
    "friends": {
      "$uid": {
        ".read": "auth != null && auth.uid === $uid",
        "$f": { ".write": "auth != null && (auth.uid === $uid || auth.uid === $f)" }
      }
    },
    "requests": {
      "$uid": {
        ".read": "auth != null && auth.uid === $uid",
        "$from": { ".write": "auth != null && (auth.uid === $from || auth.uid === $uid)" }
      }
    },
    "invites": {
      "$uid": {
        ".read": "auth != null && auth.uid === $uid",
        "$g": { ".write": "auth != null" }
      }
    },
    "games": {
      "$g": {
        ".read": "auth != null",
        ".write": "auth != null && ((!data.exists() && newData.child('w').val() === auth.uid) || data.child('w').val() === auth.uid || data.child('b').val() === auth.uid || (!data.child('b').exists() && newData.child('b').val() === auth.uid))"
      }
    }
  }
}

          ملاحظة مهمة: قواعد Realtime Database تقدر تتحقق من هوية اللاعبين (مين يكتب في المباراة)، لكنها ما تقدرش تتحقق من صحة نقلة الشطرنج نفسها (هل هي قانونية فعلاً). التحقق من قانونية النقلة يحصل حاليًا في متصفح كل لاعب. لمنع الغش الكامل 100% محتاج طبقة إضافية (Cloud Function تتحقق من كل نقلة قبل قبولها)، وهي خطوة ممكن تُضاف لاحقًا لو احتجتها.

          ملاحظة: دخول جوجل لا يعمل من ملف مفتوح بـ file://، لازم الموقع يكون مرفوعًا على استضافة أو localhost.

          القواعد المطبَّقة داخل المحرّك

          كل نقلة تمرّ على فحص قانوني كامل قبل تنفيذها، محليًا وأونلاين، ولا يمكن لعب نقلة تترك ملكك تحت الكش.

          حركة كل قطعة

          كل قطعة بمداها الصحيح، بلا قفز غير مشروع.

          التبييت

          فقط إن لم يتحرك الملك ولا الرخ، والمربعات خالية، والملك لا يمر بمربع مهدَّد.

          الأخذ بالمرور

          في النقلة التالية مباشرة لدفعة البيدق المزدوجة، وإلا سقط الحق.

          ترقية البيدق

          تختار بنفسك: وزير، رخ، فيل، أو حصان.

          الكش والمات

          مربع الملك يتلوّن بالأحمر، والمات ينهي المباراة بإعلان الفائز.

          عند الجمود أو التكرار أو الخمسين نقلة، يفوز صاحب القطع الأعلى قيمة.
